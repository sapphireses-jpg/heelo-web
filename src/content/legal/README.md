# 게시용 약관 파일

`<문서>/<버전>.md` (문서: terms, privacy, location, community). 작성 방법은 저장소 `README.md`의 「약관 새 버전 올리는 법」을 봅니다.

- 원본은 앱 저장소 `docs/legal/public/`입니다. 법률 검토가 끝나고 오너가 알려 주면 그때 `v1.0` 파일을 만듭니다.
- 옮길 때 「법률 검토 쟁점」 절과 검토용 주석(`<!-- -->`, `[검토 …]` 등)은 빼고 본문 문장만 옮깁니다.
- published 파일에 `[`로 시작하는 자리표시, 「검토용 주석」「법률 검토 쟁점」「개발 확인」「DPA 확인」, HTML 주석이 있으면 빌드 검사가 실패합니다.
