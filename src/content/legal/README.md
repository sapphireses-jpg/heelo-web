# 게시용 약관 파일

`<문서>/<버전>.md` (문서: terms, privacy, location). 작성 방법은 저장소 `README.md`의 「약관 새 버전 올리는 법」을 봅니다.

- 원본은 앱 저장소 `docs/legal/public/`입니다. 정식 버전 전에는 `<문서>/preview.md`(임시 초안)를 `npm run sync-legal-preview`로 가져와 보여 줍니다(직접 고치지 않음).
- 법률 검토가 끝나고 오너가 알려 주면 그때 `v1.0` 파일을 만듭니다.
- 옮길 때 「법률 검토 쟁점」 절과 검토용 주석(`<!-- -->`, `[검토 …]` 등)은 빼고 본문 문장만 옮깁니다.
- published 파일에 `[`로 시작하는 자리표시, 「검토용 주석」「법률 검토 쟁점」「개발 확인」「DPA 확인」, HTML 주석이 있으면 빌드 검사가 실패합니다.

- 정식 v1.0(M 7007, 방송 #724): `v1.0.md` 3개는 앱 저장소 `docs/legal/public/` 원문(첫 줄 주석만 뺌)을 `status: draft`로 먼저 두었다가 공고일 2026-11-05에 `published`로 바꾸고 `preview.md` 3개를 지웁니다. 시행일(2026-12-05) 전에는 `/legal/<문서>/`가 이 시행 예정 판을 본문으로 보여 줍니다.
